TAR UMT Study Dashboard — 202609 Semester

1. Preview locally: run `python -m http.server 8000` inside this folder, then open http://localhost:8000.
2. To install as an Android/iPad PWA, deploy this folder to an HTTPS static host (e.g. GitHub Pages / Netlify). Open the HTTPS link and choose Add to Home Screen / Install app.
3. Import TAR_UMT_202609_Calendar.ics into Google Calendar via Settings > Import & export > Import. Prefer a separate calendar.
4. Calendar includes official classes, study, workouts, and Thursday overlapping classes with warning. All have 5-minute VALARM; actual notification delivery depends on calendar settings and device permissions.
5. Recurrences run weekly for 7 weeks, 2 Nov–20 Dec 2026. Holidays, makeup classes, and exam changes must be checked against official updates.
6. Personal modifications in the app are stored locally in the browser, not synced to Google Calendar.
7. Never import the ICS twice without removing the previous import; doing so may duplicate events.
8. The Thursday timetable conflict has NOT been resolved.
